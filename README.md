# Omega AI LLC — Company Website

The official website for [Omega AI LLC](https://omega2ai.com), an autonomous systems architecture firm specializing in local-first AI, edge inference, and close-to-metal optimization.

## What's Inside

- **Living Neural Constellation** — 280-particle Three.js background with auto-rotation, mouse repulsion, and traveling signal packets
- **3D Holographic Hero** — Mouse-reactive 3D tilt, floating animations, pulsing glow effects
- **Animated Trust Bar** — Scroll-triggered count-up statistics with 3D hover tilt
- **How We Work** — 4-step engagement process with pricing disclaimer
- **FAQ Section** — 8 common questions with accordion expand/collapse
- **Omega 3.0 Showcase** — Full product showcase with model table, benchmarks, images, vision, memory graph, autonomous demo, and closing the loop
- **Privacy Policy & Terms** — Modal overlays with full legal text
- **Contact Form** — Service inquiry form with dual email support

## Tech Stack

- React 19 + TypeScript + Vite
- Tailwind CSS 3.4 + shadcn/ui
- Three.js (neural constellation particle system)
- GSAP ScrollTrigger (scroll-driven animations)
- Glass morphism UI with hologram shimmer effects

## Getting Started

```bash
npm install
npm run dev     # Start dev server
npm run build   # Production build
npm run preview # Preview production build
```

## Deployment

This repo includes a GitHub Actions workflow that auto-builds and deploys to GitHub Pages on every push to `main`.

To enable:
1. Go to **Settings → Pages** in your GitHub repo
2. Set **Source** to "GitHub Actions"
3. Push to `main` — the workflow handles the rest
