3. Google Sign-In and Google Workspace (Omega 3.0)

The Omega 3.0 Google Workspace connection is an installed desktop integration. It connects only when you start the connection and approve Google's consent screen.

Authorization and requested scopes

Omega uses the OAuth 2.0 Authorization Code flow with PKCE, an independent one-time state value, and a loopback callback on your device. The desktop integration does not use or accept a Google OAuth client secret.

Omega requests these scopes:

  • openid
  • https://www.googleapis.com/auth/userinfo.email
  • https://www.googleapis.com/auth/gmail.modify
  • https://www.googleapis.com/auth/calendar
  • https://www.googleapis.com/auth/tasks
  • https://www.googleapis.com/auth/drive

Data processing and storage

Data How it is handled
OAuth client ID A public desktop-application identifier included in the installed provider
Access and refresh credentials Credentials are held only in memory by the local provider process for the active connection
Google Workspace content Requested from Google only for the tool operation you invoke and returned locally to Omega
Operational state Bounded non-secret status, revision, cursor, and action state kept by the local process as needed to complete or reconcile an operation

The provider sends authorized Workspace requests directly from your device to Google's HTTPS API endpoints. Omega AI LLC does not operate an intermediary server for this connection. The provider does not persist Google credentials or Workspace payloads to its package, command-line arguments, environment, Git repository, logs, or provider files.

How Omega uses Workspace data

  1. Confirm the connected Google identity and connection status.
  2. Read or change Gmail, Calendar, Tasks, Drive, or Docs data only when you invoke or approve the corresponding local tool.
  3. Return the result to the local Omega runtime for the user-requested task.

Omega may retain a user-visible result or derived local memory on the same user-controlled installation only when you invoke or approve that product behavior. Google user data is not sold or used for advertising. It is not used to train shared or generalized AI models.

Omega's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Sharing

Workspace content travels between your local installation and Google's APIs for the operation you request. Results remain on your local installation unless you deliberately send or share them using a Google Workspace action. Omega AI LLC does not disclose this data to advertising platforms, data brokers, or unrelated third parties.

Retention and deletion

  • The Google Workspace provider does not persist OAuth credentials or Workspace payloads after its local process ends.
  • Disconnect makes a bounded best-effort request to revoke Google's credential grant, then destroys the local in-memory credential session. Shutdown also destroys the local session.
  • You control any user-approved results or derived memory retained by the local Omega installation and may remove that local data using Omega's local data controls.
  • You can also remove Omega from Google Account → Connections.
