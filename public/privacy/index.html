3. Google Sign-In and Google Workspace (Omega 3.0)

When you use Sign in with Google from an Omega 3.0 installation, Omega requests only the OAuth scopes required for the product ceiling:

  • OpenID identity (openid, email)
  • Gmail (gmail.modify) — read and bounded changes; no permanent-delete scope
  • Calendar, Tasks, and Drive — as enabled in your connection settings

What Omega stores, and where

Data Storage
Google OAuth client secret (owner-configured once) AES-256-GCM connector vault on the Omega host
Refresh / access tokens AES-256-GCM connector vault, bound to your connection passphrase
Connection contract (capabilities, authority, retention) Local guardian state — configuration only, no message bodies
Raw Workspace observations on intake Local SourceLedger (plaintext before Guardian screening)
Derived memory after screening Local Omega memory (episode SRAM → DeepSleep → filesystem/graph)
Action / sync operational state Local ledgers: IDs, revisions, cursors, counts, digests — not Workspace payload content

Google Workspace payloads and secrets are not placed in application logs, test output, Git, provider cursor state, or HUD progress labels.

How Omega uses Workspace data

  1. Ingest selected mail, calendar, tasks, and files into local memory.
  2. Align standing work after you approve a package.
  3. Act only inside the connection contract and, for autonomous standing work, an exact approved grant. Send-class Gmail operations require send authority and revision-bound approval when configured that way.

Omega does not sell Workspace data or use it to advertise to third parties.

Sharing

Omega does not transmit your Workspace content to Google beyond the API calls you authorize, and does not share that content with other product vendors as part of this connection.

Retention and deletion

  • Retention follows the connection contract you set in Omega.
  • Disconnect revokes Omega’s Google authority, then clears local credentials and connector state according to that contract.
  • You can also remove Omega from Google Account → Connections.

4. Children
